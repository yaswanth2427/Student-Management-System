# 🎓 Student Management System

## 📌 About the Project
The Student Management System is a Java application that allows
users to manage student records through a menu-driven interface.

It uses JDBC to connect Java with a MySQL database and supports
CRUD operations for managing student information.

## 🚀 Features
- User login with limited attempts
- Add new student records
- Search students by ID
- Search students by name
- Update student information
- Delete student records
- Input validation
- Student sorting
- Student dashboard
- Display student records in a formatted table

## 🛠️ Technologies Used
- Java
- JDBC
- MySQL
- Eclipse IDE
- MySQL Workbench

## 🧠 Concepts Implemented
- Object-Oriented Programming
- Classes and Objects
- Encapsulation
- Exception Handling
- Database Connectivity
- CRUD Operations
- SQL Queries

## 🗄️ Database
MySQL is used to store and manage student information.
JDBC establishes the connection between the Java application
and the database.

## 🎯 Project Objective
To build a database-driven application that demonstrates
Java programming, SQL, JDBC, and student record management.
